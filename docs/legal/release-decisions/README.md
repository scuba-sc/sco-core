# Release decisions

One file per decision that a release depends on and that a person, not CI, has to make: licensing
(for example the plugin licence, [options](../plugin-licensing-options.md)), the basis for shipping a
game-derived file, approval of a specific SDK release. Name: `YYYY-MM-DD-<topic>.md`.

Each file states: the decision, who made it and when, what it was based on (with links), the commit
and artifact hashes it applies to where relevant, and anything it leaves open.
