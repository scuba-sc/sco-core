## Proposed coordinates

SDK 2.2.0 for `core`, `legacy`, `core-source` and `host-source-sc`; frozen plugin ABI 1.1
unchanged; game pack 0.4.0 unchanged unless the game tables below land, in which case the
additive-service minor rule in [game-pack policy](../../game-pack.md) would raise it to 0.5.0.
The profile list is unchanged: `core`, `game-sc`, `legacy`, `core-source`, `host-source-sc`.

## Decisions the maintainer needs to make

1. **Approve or change the profile assignments above** for the landed items, and record the
   reviewed source commit.
2. **Absent items:** hold 2.2.0 for the game tables and the scaffolder, or approve the candidate
   without them (the release notes draft already describes them as outside this candidate).
3. **game-sc overlay identity:** the overlay binds the exact core archive digest, so an overlay
   rebuilt over the 2.2.0 core differs in bytes from the published `sco-sdk-game-sc-0.4.0.zip`
   while keeping the same file name. Options: publish a new game-pack coordinate even without
   service changes, or ship 2.2.0 without a new game-sc overlay. Neither is decided here.
4. **Evidence accepted for the candidate:** C# builder not compiled locally, Linux and native
   Windows builds of the merged branch not run locally, nothing run in the game. Hosted CI on the
   merged `main` commit is the first evidence for those.
